# Reflective Enabler Playbook

End-to-end standard operating procedure for the **ICT and Digital Platform Enabler** role on Reflective CSI-funded programmes in South Africa.

Open [`index.html`](./index.html) in a browser. Use **Field kit** on session days, **Print / PDF** for a hard copy, and the pocket card at the bottom in the kit lid.

## What this closes

Training already covers digital tools, lab rules, and reporting. It did not specify how to *kickstart* a live Numerate session: one instruction, show the screen, wait until most learners are on track, then continue — and start every class on the **Numbers** journey, not Data Literacy.

This playbook adds:

- A four-phase operating map (recruit → train → implement → review)
- A RACI matrix (Enabler, educator, ICT Manager, School Success, school champion)
- The On-Track Gate kickstart protocol and word-for-word learner script
- A 9–11 minute training video shot list
- Prep / kickstart / during / close-out checklists
- Troubleshooting, KPIs, and a printable pocket card

## How to share with Enablers

1. Send the `index.html` file (self-contained; works offline after fonts cache).
2. Or host the folder and share the URL.
3. During Module 2–3 training, play the kickstart video (once produced) and tick the checklists together.
